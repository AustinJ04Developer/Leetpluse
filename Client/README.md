# ⚡ LEETPULSE — Client (Frontend Application)

This directory contains the React 18 + Vite frontend application for **LeetPulse**.

## 🚀 Quick Start (Client)

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Configure Environment Variables**:
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
   Set `VITE_API_URL` and `VITE_SOCKET_URL` to point to your running backend server (e.g. `http://localhost:5000/api` and `http://localhost:5000`).

3. **Run Development Server**:
   ```bash
   npm run dev
   ```

4. **Build for Production**:
   ```bash
   npm run build
   ```

For full system architecture, role details, and backend setup instructions, refer to the main [Root README](../README.md).
